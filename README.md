# У Антонио — YML для Яндекс Бизнеса

Автоматическая связка для меню пиццерии «У Антонио».

**Источник:** https://uantonio.tb.ru/  
**YML-фид:** https://raw.githubusercontent.com/iuliialapace/u-antonio-yml/main/menu.yml

## Как работает

1. Меню и цены редактируются на сайте Т-Банка.
2. GitHub Actions каждые 3 часа проверяет публичный каталог.
3. `scrape_tb_to_yml.py` формирует `menu.yml`.
4. Если сайт временно не читается или найдено слишком мало позиций, рабочий YML не перезаписывается.
5. Яндекс Бизнес читает одну постоянную ссылку на `menu.yml`.

## Подключение к Яндексу

В Яндекс Бизнесе выбрать источник **YML-фид** и указать:

`https://raw.githubusercontent.com/iuliialapace/u-antonio-yml/main/menu.yml`

## Важно

Временную «Пиццу недели» лучше оформлять как акцию, а не оставлять её акционную цену постоянной ценой товара.

В коде есть защита для уже найденных старых ценовых ошибок: она срабатывает только на конкретные старые значения. Любая новая цена, которую вы установите позже, будет принята как новая.
